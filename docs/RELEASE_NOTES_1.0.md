# Production Line Dataset 1.0.0

Первый завершённый выпуск локальной агентской предразметки кадров.

## Основное

- нативный запуск на macOS, Ubuntu/Debian и Windows 11, дополнительный WSL2;
- ограниченные режимы `1X` и `2X` с видимой причиной каждого вызова;
- неизменяемая история попыток и ревизий;
- детализация по исходным фрагментам без фильтров и перерисовки;
- полноэкранный ручной редактор с черновиками, undo/redo и серверной проверкой;
- экспорт только утверждённой ревизии в YOLO Segmentation с классами `0/1/2`;
- совместимый импорт старых ZIP с обязательной ручной проверкой;
- миграции SQLite с резервной копией и восстановление после перезапуска;
- матричный CI: macOS, Ubuntu и Windows × Python 3.11/3.12.

## Безопасность данных

Сервер доступен только локально. Runtime-кадры, SQLite, резервные копии, журналы
и экспортные ZIP исключены из Git. Исходные изображения не изменяются.

Перед эксплуатацией ознакомьтесь с разделами «Ограничения качества» и
«Персональные данные» в README и завершите платформенный реальный smoke-чек-лист.
